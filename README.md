# Tindahan ordering agent

A small, dependency-free Python prototype for mixed Tagalog/English store orders.

## Design commitments
- Catalog prices are indicative; a live server quote is authoritative.
- Never place an order before explicit confirmation of a specific quote.
- Never infer quantities from empty shelves or silently substitute products.
- Mock APIs and sample conversations are invented because source resources were not supplied.

Implementation and usage instructions will be added as the prototype is completed.
